# Teaching theory to a producer

The user hears well and produces well; formal terms and keyboard fingering are the gap. Explain from sound and notes toward names, never the other way round.

## The explanation ladder

Stop at the lowest rung that answers the question; go up only when asked or when it unlocks the idea.

1. **What to play** — notes with octaves and MIDI numbers.
2. **What it sounds like** — "darker", "it floats", "it pulls back home".
3. **What changed** — the specific notes that moved, and by how much.
4. **The name** — the theory term, once the idea is already understood.
5. **The general rule** — how to reuse it elsewhere.

## Example: "use modal interchange from the parallel minor"

Not just the term. Instead:

> In C major, the IV chord is **Fmaj7: F A C E**. Try **Fm7: F Ab C Eb** instead. Two notes drop by a semitone — A → Ab, E → Eb (MIDI 69 → 68, 64 → 63 in the octave above C3). Those are notes from **C minor**, the "dark twin" of C major (same home note, different scale). Borrowing a chord from it while staying in C major is called **modal interchange**. The effect is bittersweet — the moment in a soul song where the chord sighs before going home. It works on other chords too: Ab major (bVI) and Bb (bVII) are the other common loans.

## Habits

- **Use their words.** If they say "the sad chord", reuse that phrase alongside the name.
- **Show diffs, not tables.** "Only the top note changes" beats a spelled-out scale.
- **Anchor to the keyboard**: white/black keys, "one key to the left", hand shapes. Give the hand split the script reports.
- **One concept per explanation.** If two ideas are involved, explain the one that matters for their next move.
- **Name the trade-off.** "Richer, but it'll fight with a busy bass — keep it if the bass stays on roots."
- **Offer, don't impose, depth**: end with a short offer ("want the theory behind why that works?") only when there's genuinely more worth knowing.
- **Ambiguity is a lesson, not a failure**: "these four notes are both Abmaj7 and Fm9 — the bass note decides" teaches more than picking one.

## Plain-language glossary

| Term | Say it as |
|---|---|
| tonic | home chord |
| dominant | the chord that pulls back home |
| resolution | the tension releasing into the next chord |
| inversion | same chord, different bottom note |
| voicing | which notes of the chord you play and where |
| extension (9, 11, 13) | extra colour notes stacked on top |
| altered dominant | a "pull home" chord with deliberately crunchy colour notes |
| mode | the same notes with a different home note — each has its own mood |
| modal interchange | borrowing a chord from the darker/brighter twin key |
| secondary dominant | a chord that makes the *next* chord feel like a temporary home |
| tritone substitution | swapping the pull-home chord for one a semitone above the target, so the bass slides down |
| voice leading | how each note moves to the next chord |
| pedal point | one bass note held while chords change above it |
| guide tones | the 3rd and 7th — the notes that make a chord's identity |
